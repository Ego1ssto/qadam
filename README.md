# Qadam — адаптивная подготовка к БИЛ / НИШ / РФМШ

Платформа подбирает задачи по математике и логике под уровень ученика (Elo по темам),
генерирует вариации задач через Claude и даёт подсказки при ошибке. Интерфейс и задачи на RU и KZ.

## Запуск

```bash
cd backend && uv venv && uv pip install fastapi "uvicorn[standard]" sqlalchemy pyjwt anthropic
export ANTHROPIC_API_KEY=...   # необязательно: без ключа подсказки офлайн, вариации недоступны
.venv/bin/uvicorn app.main:app --port 8000
```

```bash
cd frontend && npm i && npx vite
```

Откройте http://localhost:5173. Демо-аккаунты: `student@demo.kz` и `tutor@demo.kz`, пароль `demo123`
(код приглашения репетитора — `DEMO01`). При запуске база SQLite заполняется 14 темами × 5 задач (новые темы досеваются и в уже существующую базу).
Для Postgres задайте `DATABASE_URL`.

## Архитектура

| Модуль | Что делает |
|---|---|
| `backend/app/core.py` | Модели БД, Elo-алгоритм, проверка ответов |
| `backend/app/main.py` | REST API: auth (JWT), ученик, репетитор, исследование |
| `backend/app/llm.py` | Claude: вариации задач (structured output) и подсказки |
| `backend/app/sim.py` | Симуляция «Elo против случайного подбора» |
| `backend/app/seed_data.py`, `seed_extra.py` | Стартовый банк: 14 тем, 70 задач RU/KZ |
| Профиль (`/api/profile`) | Класс, цель (БИЛ/НИШ/РФМШ), город, дата экзамена, уровень, серия дней, сильная и слабая темы, смена пароля, вступление к репетитору по коду |
| `frontend/src/App.tsx` | React: ученик, репетитор, графики, KaTeX |

### Адаптивный алгоритм
- У ученика свой рейтинг по каждой теме, у задачи — рейтинг сложности (оба стартуют по шкале Elo).
- Вероятность решить: `P = 1 / (1 + 10^((R_задачи − R_ученика)/400))`.
- После ответа рейтинги ученика и задачи обновляются, K-фактор ученика убывает с числом попыток.
  Верный ответ после подсказки засчитывается как 0.6.
- Следующая задача: самая слабая тема (с вероятностью 25% — случайная) и задача с рейтингом, ближайшим к целевому `P ≈ 0.7`.

### LLM
- **Вариации по шаблону:** репетитор нажимает «Сгенерировать вариации» у одобренной задачи. Claude
  возвращает JSON по схеме (RU, KZ, решение, ответ). Вариации попадают в банк со статусом «На проверке»,
  а ученики видят их только после одобрения репетитором.
- **Ответ проверяет код** (числа, дроби, запятая или точка). LLM только подсказывает и не раскрывает ответ.

### Оценка (для защиты)
Вкладка «Исследование» у репетитора или `python -m app.sim`: 200 виртуальных учеников × 60 задач.
Адаптивный подбор даёт примерно вдвое больший прирост истинного уровня, чем случайный (+46 против +23).
Ошибка оценки рейтинга (RMSE) у адаптивного подбора пока не лучше случайного — это направление для улучшений
(например, начальный диагностический тест).
